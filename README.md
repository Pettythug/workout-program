# Workout Program

Welcome to the Workout Program repository. This software is a hybrid gym-logging application currently undergoing a migration from a Vanilla JS/HTML architecture to a modern React Single Page Application (SPA).

## High-Level Architecture
- **Production Legacy Files:** The core live applications are `gymlog-ultimate.html` and `circuit-training-pro.html`. 
- **React Migration:** The `/gymlog-react/` directory contains the ongoing React migration.
- **Ecosystem:** The app uses Google Sheets as a backend for data persistence and multi-user sync.

## Project Management & Routing
This project strictly follows a Jira-ticket Sandbox Developer workflow.
- **Active Tasks:** All active work, Jira tickets, and current tactical states are located in the `docs/jira_tasks/` directory.
- **Backlog:** The ongoing React migration backlog is located at `docs/migration_backlog.md`.
- **Developer Protocol:** For strict architectural and coding rules specific to this project, read `docs/DEVELOPMENT_PROTOCOL.md`.
